# LumineDroid
**An open-source custom Android based on AOSP, built for better performance and user experience.**

## About  
LumineDroid is an open-source project that aims to create a custom Android operating system based on the Android Open Source Project (AOSP).  
Our goal is to deliver a fast, stable, and user-friendly Android experience while maintaining a clean and modifiable codebase for the community.

We focus on improving performance, design consistency, and customization without sacrificing stability.  
LumineDroid is built by the community, for the community — empowering users and developers to shape their own Android experience.
